# Dati

- `openngc.json.gz.b64`: estratto compresso del catalogo OpenNGC. Origine, licenza e attribuzione in `OPENNGC-ATTRIBUTION.md`.
- Specifiche di telescopi e camere: dati locali con provenienza per marca/modello e limiti descritti in `EQUIPMENT-SOURCES.md`.
- I record mantengono unità esplicite (gradi per coordinate, primi d'arco per dimensioni, mm per sensori e focali, μm per pixel). Campi non disponibili restano vuoti, non vengono inferiti dal nome.
