OurSky includes a filtered extract of OpenNGC, by Mattia Verga and contributors.
Source: https://github.com/mattiaverga/OpenNGC
License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
The extract contains deep-sky object identifiers, types, J2000 coordinates, constellations,
angular axes, magnitudes, Messier cross-identifications, common names and notes.
OurSky maps this source data into its catalog interface.
